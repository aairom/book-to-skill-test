# Input folder
   - All the input documents which are required for the applications are to be found in "input" folder under the parent folder
   - All the documents in "input" folder should be processed recurssively.

# Output folder
   - All the output documents from application execution which are asked to be provided should be writen in timestamped format in "output" folder
   - The result documents should be written in "output" folder, if the "output" folder does not exist, it should be created
