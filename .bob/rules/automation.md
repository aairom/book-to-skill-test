# Automation Scripts:
   - All the BASH scripts, should be written in "scripts" folder under the parent folder
   - Provide a script to lauch the application in detached mode which displays the URL to access the application on the console
   - Provide a script to shutdown the application gracefully
   - Provide a script which cleans-up the folder project removing "node-modules" and ".venv" and '__pycache__' for the end of the project
   - If a local server is needed, it must start with a single command
   - If container images are pulled, provide a script which deletes all container images pulled locally for the end of the project
